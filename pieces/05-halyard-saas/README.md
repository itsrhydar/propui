# 05 Halyard SaaS revenue and usage

A dark, glassy revenue and usage desk for an API platform's revenue team with an MRR figure that counts up on load. References gave the mood and a few patterns (glass-dark
panels, big light numerals, sparkline metric cards, a crosshair chart, a swap-style card, a status-pill table);
the product, data and layout are original. Mint for gains, coral for falls, violet for traffic peaks.

Interactions: pick a metric card (MRR, active workspaces, API requests) to drive the chart; switch 1D, 1W, 1M; hover
the chart for a crosshair readout; build a quote (plan, seats with a stepper, monthly or annual billing, totals
that roll); sort the subscriptions table; hover the half-hour load bars; collapse the sidebar.
